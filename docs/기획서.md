# 🏅 sideline365 — 제품 기획서

> 스포츠 통합 관리 앱. 기록을 측정하고 코치와 공유해 **더 나은 운동 성과**를 만든다.
> 여기에 **스포츠 스타 선수의 훈련 시스템을 팔로우**하는 기능을 더해, 최고 선수의 루틴을 내 훈련으로 연결한다.

- 문서 버전: v0.2
- 최종 수정: 2026-07-04
- 상태: MVP 구현 완료 + 신규 기능(스타 선수 훈련 팔로우) 기획

---

## 1. 제품 개요

### 1.1 한 줄 정의
선수는 **종목별로 훈련하고 기록을 측정**하며, **코치와 공유**해 피드백을 받고,
**스타 선수의 훈련 루틴을 팔로우**해 최고 수준의 훈련 시스템을 따라 한다.

### 1.2 문제 정의
- 기록이 노트·메모·기억에 흩어져 있어 **성과 추세를 보기 어렵다.**
- 코치와 선수가 기록을 공유·피드백할 **공용 공간이 없다.**
- 종목마다 필요한 기능(측정 vs 훈련 가이드)이 **제각각**이라 통합 앱이 없다.
- "잘하는 선수는 어떻게 훈련할까?"에 대한 **믿을 만한 루틴 레퍼런스가 없다.**

### 1.3 솔루션
하나의 앱에서 **① 측정 · ② 공유/피드백 · ③ 종목별 훈련 가이드 · ④ 스타 선수 훈련 팔로우**를 제공한다.

## 3. 핵심 가치 제안
1. **종목 확장성** — 새 종목은 레지스트리에 항목 하나만 추가하면 앱 전체에 반영.
2. **측정→공유→피드백 루프** — 기록이 곧바로 코치 피드백으로 이어진다.
3. **스타 선수 훈련 팔로우** — 최고 선수의 루틴을 내 훈련 레퍼런스로.

## 5. 신규 기능 — 🌟 스포츠 스타 선수 훈련 팔로우

### 5.1 개념
각 종목별로 앱이 큐레이션한 **스타 선수 프로필**을 제공한다.
각 선수는 **운동 루틴 / 훈련 시스템**(주간 스케줄·단계별 훈련·강도)을 가진다.
사용자는 스타 선수를 **팔로우**하고, 루틴을 열람하며, 원하는 루틴을 **내 훈련으로 담아** 따라 한다.

### 5.2 사용자 스토리
- (선수) "손흥민은 비시즌에 어떻게 훈련하지?" → 프로필에서 주간 루틴을 본다.
- (선수) 마음에 드는 루틴을 **팔로우**하면 홈 피드에 그 선수의 루틴이 모인다.
- (선수) 루틴의 "**내 훈련에 담기**"로 개인 훈련 계획에 복사해 체크하며 수행한다.
- (코치) 선수에게 특정 스타 루틴을 **추천**한다. *(2차 확장)*

### 5.3 화면 구성
| 화면 | 경로 | 내용 |
| --- | --- | --- |
| 스타 선수 목록 | `/stars` | 종목 필터 + 선수 카드(사진·팀·포지션·팔로워 수·팔로우 버튼) |
| 스타 선수 프로필 | `/stars/[athleteId]` | 프로필/이력/태그 + **훈련 루틴 목록** + 팔로우 버튼 |
| 루틴 상세 | `/stars/[athleteId]#routine-[id]` 또는 별도 페이지 | 주간 스케줄·단계별 항목(세트/반복/시간) + "내 훈련에 담기" |
| 홈 피드 | `/` 내 섹션 | 내가 팔로우한 선수들의 루틴/업데이트 모아보기 |
| 종목 허브 연동 | `/sports/[sportId]` | "이 종목의 스타 선수" 섹션 → `/stars?sport=` 링크 |
| 내 훈련 계획 | `/training` *(2차)* | 담아둔 루틴 수행 체크리스트 |

### 5.4 기능 상세
1. **팔로우/언팔로우** — 사용자↔스타 선수 M:N 관계. 팔로워 수 집계.
2. **루틴 열람** — 카테고리(웜업/근력/기술/컨디셔닝/회복), 주간 배치, 항목별 세트·반복·시간·팁.
3. **내 훈련에 담기** *(2차)* — 루틴을 개인 훈련 계획(`TrainingPlan`)으로 복사, 수행 체크.
4. **피드** — 팔로우한 선수 기준 루틴 카드 모아보기.
5. **코치 추천** *(2차)* — 코치가 담당 선수에게 스타 루틴 추천 → 선수 피드에 표시.

### 5.5 콘텐츠 예시 (초기 시드)
| 종목 | 스타 선수(예시) | 대표 루틴 예시 |
| --- | --- | --- |
| 🏊 수영 | 케일럽 드레셀, 케이티 러데키, 황선우 | 스프린트 세트, 지구력 디스턴스 세트, 드라이랜드 근력 |
| ⚽ 축구 | 손흥민, 케빈 더브라위너, 얼링 홀란드 | 스프린트·민첩성, 마무리 훈련, 코어·회복 |
| 🥍 라크로스 | 폴 라빌(Paul Rabil) 등 | 월 볼 루틴, 샷 파워, 컨디셔닝 |

> 콘텐츠는 사실 기반의 **일반적 훈련 원리**로 구성하며, 특정인의 비공개 정보를 단정하지 않는다.
> (스타 선수는 큐레이션 콘텐츠이며 앱의 실제 로그인 사용자가 아님.)

## 6. 데이터 모델

### 6.1 기존 (구현됨)
`User`(role: ATHLETE/COACH), `CoachAthlete`(코치↔선수), `Record`, `Comment`

### 6.2 신규 (스타 선수 팔로우)
```prisma
model StarAthlete {
  id           String   @id @default(cuid())
  sport        String   // 종목 레지스트리 id
  name         String   // 한글명
  nameEn       String?
  nationality  String?
  team         String?
  position     String?
  bio          String?
  imageUrl     String?
  achievements String?  // 주요 이력(요약)
  tags         String?  // 콤마 구분 태그
  createdAt    DateTime @default(now())

  routines  AthleteRoutine[]
  followers Follow[]

  @@index([sport])
}

model AthleteRoutine {
  id            String   @id @default(cuid())
  athlete       StarAthlete @relation(fields: [athleteId], references: [id], onDelete: Cascade)
  athleteId     String
  title         String
  category      String   // 웜업 | 근력 | 기술 | 컨디셔닝 | 회복
  level         String   // 입문 | 중급 | 고급
  schedule      String?  // 예: "주 4회", "비시즌"
  summary       String
  items         RoutineItem[]
  order         Int      @default(0)

  @@index([athleteId])
}

model RoutineItem {
  id         String @id @default(cuid())
  routine    AthleteRoutine @relation(fields: [routineId], references: [id], onDelete: Cascade)
  routineId  String
  order      Int
  title      String
  detail     String?
  durationMin Int?
  sets       Int?
  reps       String?  // "12회", "실패 지점까지" 등 자유 형식

  @@index([routineId])
}

model Follow {
  id        String   @id @default(cuid())
  user      User        @relation(fields: [userId], references: [id], onDelete: Cascade)
  userId    String
  athlete   StarAthlete @relation(fields: [athleteId], references: [id], onDelete: Cascade)
  athleteId String
  createdAt DateTime @default(now())

  @@unique([userId, athleteId])
  @@index([userId])
  @@index([athleteId])
}
```
> `User`에 `follows Follow[]` 관계 추가 필요.

### 6.3 2차 확장 모델(개념)
```prisma
model TrainingPlan {        // 내가 담은 루틴(개인 훈련 계획)
  id, userId, sourceRoutineId?, title, createdAt
  entries TrainingEntry[]
}
model TrainingEntry {       // 계획 항목 + 수행 체크
  id, planId, title, detail, done Boolean, doneAt DateTime?
}
```
